Praveen Birthday Website
1. Unzip this folder.
2. Open the 'birthday' folder in VS Code (File > Open Folder).
3. Double-click index.html to open it in the browser.

Folders: photos/ (memory + hero + favourites), family/, music/ (song covers).
Optional: put song1.mp3 ... song5.mp3 in music/ for the pink play bar.
Birthday date: change BIRTHDAY in script.js.
